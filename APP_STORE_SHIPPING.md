# App Store Shipping

This repository contains no signing material, Archive, IPA, App Store configuration, or release logs. Public documentation must not infer live App Store availability from a repository URL.

**Verified backend status (2026-10-09):** version 2.6, build 50 is **Ready for Distribution** in App Store Connect. The owner confirmed initiating release. The approved build, subscription, price and availability settings were not replaced during this check.

**Public availability: NOT YET VERIFIED.** The China storefront page returned HTTP 404 and Apple's lookup service returned no matching result at the latest check on 2026-10-09. Backend release state is not proof that storefront propagation is complete. [App Store listing](https://apps.apple.com/cn/app/id6813336672) may remain unavailable until distribution finishes.

Local input-experience development is separate from that approved build. The latest completed build/install evidence in the development records is 2.6 (55), dated 2026-10-04. Its engine evaluations and remaining device-acceptance limitations are described in [TESTING.md](TESTING.md); they are not results for the approved build 50.

Archive creation, distribution validation, upload, processing, review approval, and public release are separate milestones. A later development build is not an App Store release unless its own submission and release are independently confirmed.
